# Strategy Review V2 — offline research tools

This package contains the separate v2 study and its frozen v1 source dependency. It is not an EA upgrade and contains no user price files, account journals or economic result report. Keep the two source folders together after extraction.

Read `strategy_review_v2/README_VI.md` and `protocol.json` before running. Python 3, g++ C++17 and tzdata 2026.4 are required. Both source test suites passed in an extracted package (24 v1 + 28 v2 tests); executable files in this final package are byte-identical to that tested extraction. Package CRC and all source SHA256 entries were verified.

Operating V2.29 and the v1 source remain unchanged. Known-history OHLC references are not native EA execution tests, BO platform returns or new forward evidence. No strategy, parameter or model is selected or activated by these tools. Private reports and outputs remain outside Git.
