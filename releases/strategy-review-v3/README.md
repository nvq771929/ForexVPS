# Strategy Review V3 — offline evaluation tools

Source-only package for frozen-candidate structural-stop and M5-open protection research, BO horizon references and retrospective stability assessment. Contains v1/v2 dependencies and a byte-identical ForexRisk header for plan tests. This is not an EA upgrade or a MetaEditor-compiled release.

Read the Vietnamese README and frozen protocol before running. Python 3, g++ C++17 and tzdata 2026.4 are required. See `VALIDATION.json` for extracted test-suite results and the exact source archive hash. All source entries and the ZIP CRC are checked by the packager.

No user price data, account journals, economic outputs or private report renderers are included. V2.29, previous research sources and operating presets remain unchanged. Known-history proxies do not establish native execution, BO platform profitability or new forward validation; no model/parameter is selected or activated.
